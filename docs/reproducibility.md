# Reproducibility guide

The current v0.2 instructions are in [reproduction.md](reproduction.md):

1. Synthetic runnable demo, no external data.
2. Released models, figures, compact evidence and SHA-256 verification.
3. Full experiment using independently obtained NASA/CALCE data in a separate run directory.

See [validation results](v02-validation.md) for exact tests and limitations. The existing research test modules remain intact. Full discovery requires excluded source-derived tables and development artifacts, and historical snapshot tests do not describe the public subset. No frozen receipt has been rewritten to make these comparisons pass.
